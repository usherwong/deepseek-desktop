# 02 · 渠道

按 ROI 从高到低。先中文（你的主力人群），再英文（放大）。

## 中文渠道

### 1. V2EX（冷启动首选，开发者多、反馈快）
- 版块：`分享创造` / `程序员`
- 标题用「Show / 分享创造」+ 痛点
- 正文：讲清楚「解决什么问题」，附 GitHub + 下载链接
- 注意：V2EX 用户会较真，把「非官方」「要自己填 key」「签名警告」主动说清楚，避免被当广告喷
- 目的：**拿第一批真实反馈 + 快速修 bug**

### 2. 小红书（小白流量最大）
- 账号：新开一个，简介写「开源工具分享」
- 发：图文（截图 + 步骤），3-5 张图
- 标签：`#DeepSeek` `#DeepSeek客户端` `#效率工具` `#AI工具` `#mac软件`
- 重点：标题命中「小白/不用命令行/能读图」，封面放「免终端」三个字
- 目的：**面向普通用户的曝光**

### 3. 知乎
- 找「有没有 DeepSeek 桌面客户端」「DeepSeek 怎么看图」「DeepSeek 本地客户端」这类问题，写带链接的回答
- 再发一篇专栏文章（教程长文）
- 目的：**SEO 长尾 + 信任背书**

### 4. B 站
- 2-3 分钟演示视频：下载→填 key→粘贴图片→得到回答
- 标题带「DeepSeek 读图 / 桌面版 / 免费开源」
- 简介 + 评论区置顶 GitHub 链接
- 目的：**视频流量 + 可复用在知乎/小红书**

### 5. 掘金 / 少数派（sspai）
- 掘金：发技术向（桥接原理、Electron 打包）
- 少数派：效率工具向（适合「小白也能用的 AI 工具」选题）

## 英文渠道（第 2 周开始）

### 6. Hacker News（Show HN）
- 标题：`Show HN: DeepSeek Desktop — a no-terminal client with native image understanding`
- 正文：第一行讲清楚两个卖点；附 demo GIF；主动回答「vs 官方」「签名」「非官方」三个问题
- 时机：**工作日早上（美东时间）**发，效果好
- 目的：一次可能带来几千访问 + 几百 star

### 7. Product Hunt
- 正式发布日上，tagline 突出「No terminal · Paste images」
- 提前准备：截图、icon、一句话介绍、第一个评论自述
- 目的：**全球曝光 + 榜单**

### 8. Reddit
- `r/LocalLLaMA`、`r/selfhosted`、`r/macapps`、`r/DeepSeek`
- 注意各版自荐规则，用「我做了个工具」的口吻，别硬广
- 目的：精准受众

### 9. Twitter/X + dev.to
- X 发线程（截图 + 卖点 + 链接）
- dev.to 发英文教程

## 渠道优先级一句话

> 第 1 周：**V2EX + 小红书 + 知乎**（拿反馈）→ 第 2 周：**HN + Product Hunt**（放大）→ 长期：**B 站 + 知乎长文 + Reddit**（长尾）。
