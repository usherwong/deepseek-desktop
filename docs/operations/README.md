## 一句话定位

> **免终端、可读图的开源 DeepSeek 桌面客户端。**

面向人群：**不想折腾命令行的普通用户**（尤其是从「DeepSeek 官方 App / 网页版」转过来、又想要「读图」的人）。

## 两个核心卖点（所有文案都围绕这两点）

1. **免终端配置** —— 不用敲命令，网页界面里填 key 就能用。
2. **无缝读图** —— 粘贴图片直接看懂（DeepSeek 官方不会看图，这个会）。

## 发布节奏（建议）

| 阶段 | 时间 | 动作 |
|---|---|---|
| 冷启动 | 第 1 周 | V2EX + 知乎 + 小红书，验证反馈、快速修 bug |
| 放大 | 第 2 周 | HN `Show HN` + Product Hunt + B 站视频 |
| 长尾 | 长期 | 持续发版、回 issue、写教程、更新关键词 |

## 目标指标（用来看效果）

- GitHub **star 数**（冷启动 1 周 > 50，1 个月 > 200 是合理目标）
- **下载量**（Releases 的 asset 下载数）
- 落地页**访问量**（GitHub Pages 流量 / 后续接个统计）
- **issue 反馈**（真实用户提的问题 = 最好的 SEO 素材）
