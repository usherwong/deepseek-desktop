# 04 · 视频脚本（拍摄教程）

目标：让别人 30 秒内看懂「这个是什么、长什么样、怎么配置、能发图」。

## 一句话定位（贯穿全程）

> **免终端、能读图的 DeepSeek 桌面客户端。**

## 分镜脚本（约 2 分钟）

| 时间 | 画面 | 字幕/旁白 |
|---|---|---|
| 0:00-0:08 | 标题字幕 | 「免终端、能读图的 DeepSeek 桌面客户端」 |
| 0:08-0:25 | 打开 App，划过聊天界面 / 侧边栏 / 会话列表 | 「原生桌面应用，mac 和 Windows 都能装」 |
| 0:25-0:50 | **设置 → 模型**，填 DeepSeek key、DeepSeek (Image) 百炼 key（**放慢**） | 「填两个 key 就能用；要识图就再填个百炼 key」 |
| 0:50-1:05 | 发一句话，正常回复 | 「文字聊天没问题」 |
| 1:05-1:40 | **拖一张截图进对话框 → 自动识别 → 回答**（核心卖点，多给几秒） | 「重点：直接发图片，它先看图再回答你」 |
| 1:40-2:00 | 结尾：下载链接 + GitHub | 「开源免费，下载链接在简介」 |

## 录制工具

- 最简单：macOS `Cmd+Shift+5` → 录制整个屏幕。
- 更好：**OBS**（免费，可加字幕、画中画、鼠标高亮）。

## 录制注意事项（重要）

1. ⚠️ **API key 绝对不能露**：录「配置」时输入框会显示字符——**用假 key 演示**（如 `sk-xxxxxxxx`），或后期打码。真实 key 露出来 = 泄露。
2. 桌面干净：关掉其它窗口、通知、和 AI 对话窗口，只留 App。
3. 鼠标慢一点，在要点处停 0.5 秒。

## 剪辑

- 工具：**剪映**（免费、中文）或 macOS **iMovie**。
- 必做：加**字幕**；识图环节**画圈/箭头**指向识别结果。
- 导出 1080p。

## 可直接照抄的旁白文案

- 开场：`不用敲命令，网页里填 key 就能用的 DeepSeek 桌面客户端。`
- 配置：`打开设置 → 模型。DeepSeek 填你的 DeepSeek key；要识图，就在 DeepSeek (Image) 里再填一个百炼 key。`
- 识图：`重点来了——直接拖一张图片进对话框，它先调用视觉模型把图看懂，再让 DeepSeek 回答你。`
- 结尾：`开源免费，mac 和 Windows 都能装。下载链接在简介。`
