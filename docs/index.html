① 免终端配置

不用装 Node、不用敲命令、不用配环境变量。打开 App，在「设置 → 模型」里填 key 就能用。

② 无缝读图

粘贴或拖入图片，App 自动调用视觉模型把图看懂，再让 DeepSeek 回答你。截图、照片、含文字的图都行。

怎么用 · 3 步

  1. 下载安装选 mac（Apple 芯片 / Intel）或 Windows 的安装包。
  2. 填两个 key设置 → 模型：DeepSeek 填 DeepSeek key，DeepSeek (Image) 填百炼 key（识图用）。
  3. 开始用新建会话，模型切到 DeepSeek (Image)，粘贴图片即可识图。

下载 · Download

所有安装包在 Releases：

  • macOS Apple Silicon → DeepSeek Desktop-*-mac-arm64.dmg
  • macOS Intel → DeepSeek Desktop-*-mac-x64.dmg
  • Windows → DeepSeek Desktop-*-win-x64-setup.exe / -portable.exe

macOS 提示「无法验证开发者」时：右键 App → 打开；或 xattr -dr com.apple.quarantine "/Applications/DeepSeek Desktop.app"。

FAQ

为什么要单独填一个百炼 key？

DeepSeek 是纯文本模型，不会看图。App 用百炼视觉模型（qwen3.7-plus）先把图转成文字，再交给 DeepSeek。

只聊天、不识图，要填百炼 key 吗？

不用。只填 DeepSeek key 即可。

这是官方产品吗？

不是。第三方开源客户端，只调用你自己的 API key，基于开源 DeepSeek Harness 构建。

收费吗？

软件免费开源；你只需付自己 API key 的调用费。
