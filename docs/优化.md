# 优化记录

> 记录 DeepSeek Desktop 已知问题与待办优化。完成一项打 `[x]` 或删除。

## 高优先级

### 1. 桥接 VL 调用加自动重试（待做）

- **现象**：偶发网络抖动时，识图报
  `llm-deepseek-image: VL request to https://.../compatible-mode/v1 failed`（TRANSPORT），整轮失败。
- **原因**：`describeImage` 只 `fetch` 一次，无重试。qwen-mm-plugins 的 Python 版（`call_openai_chat`）自带 3 次退避重试，Node 版没有。
- **修复**：给 `describeImage` 加「瞬时错误自动重试 3 次 + 指数退避」，重试条件：网络异常、429、5xx。
- **位置**：fork `deepseek-harness` 的 `packages/llm/llm-deepseek-image/src/vl.ts`；改完重走 CI 出包。
- **验证**：2026-08-15 实测 endpoint / key / `qwen3.7-plus` 均正常，确认为瞬断。

### 2. macOS 签名公证（待做）

- 现状：ad-hoc 签名，首次打开弹「无法验证开发者」，是**最主要用户流失点**。
- 修复：买 Apple Developer（$99/年）→ 配 Developer ID Application 证书 → electron-builder 公证。
- 位置：`electron-builder.yml`（`mac.hardenedRuntime`/`notarize`）+ GitHub Secrets 存证书。
